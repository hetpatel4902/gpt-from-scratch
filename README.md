# GPT From Scratch

An educational and research-oriented implementation of a GPT-1-style
autoregressive Transformer language model from scratch.

## Objectives

- Understand neural networks and mathematical foundations.
- Implement tokenization and language modelling.
- Understand self-attention and Transformer architecture.
- Implement a decoder-only Transformer.
- Train a small language model.
- Evaluate and experiment with the model.

## Technology

- Python
- NumPy
- PyTorch
- Matplotlib
- Google Colab
- Git and GitHub

## Learning Approach

The project emphasizes mathematical understanding, manual
implementations, numerical experiments and reproducibility.

This is an educational GPT-1-style implementation, not an exact
reproduction of the original 117-million-parameter GPT-1.

## Reference Paper

Improving Language Understanding by Generative Pre-Training (2018).
